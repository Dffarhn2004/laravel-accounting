## Aturan wajib
- Label, urutan grup, jumlah submenu dan lokasi submenu **tidak boleh berubah pada fase parity**; perubahan memerlukan persetujuan user sebagai ADR.
- Menu 'Simulasi & Output D&A' adalah anak **Data Transaksi**, bukan Laporan atau Aset.
- Tidak tambah menu top-level Master Data, Akuntansi atau Pengaturan seperti arsitektur UX terdahulu. Kebutuhan teknis itu boleh disusun pada level folder/controller backend, **bukan sidebar**.
- Login/welcome terpisah dari sidebar setelah pengguna masuk. 'Logout' memanggil aksi auth Laravel yang sah; jangan membuatnya hanya link kosmetik.
- URL referensi menggunakan hash routing; implementasi Laravel menggunakan route web Inertia. Mapping ke route Laravel dapat dipilih kemudian, tetapi hanya **satu** tujuan nyata per menu, tanpa placeholder yang pura-pura sudah selesai.
- Label asli dipertahankan termasuk ejaan 'Asset', 'System', 'Inputan Transaksi', 'Cashflow' dan '&' untuk parity. Produk boleh punya lokalisasi/penyempurnaan label **setelah sign-off parity**.
